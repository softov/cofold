# @facio/docs

**The registry, written down.**

Markdown references for people and for agents, generated from the declaration so they cannot drift from it.

```ts
import { reference, agentSkill } from "@facio/docs";
```

Depends on [`@facio/commands`](../commands); part of the [facio](https://github.com/softov/facio) family.
The manual page is [`docs/commands/08-generated-docs.md`](../../docs/commands/08-generated-docs.md); the whole framework is described in [`@facio/commands`](../commands).
