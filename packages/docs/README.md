# @cofold/docs

**The registry, written down.**

Markdown references for people and for agents, generated from the declaration so they cannot drift from it.

```ts
import { reference, agentSkill } from "@cofold/docs";
```

Depends on [`@cofold/commands`](../commands); part of the [cofold](https://github.com/softov/cofold) family.
The manual page is [`docs/commands/08-generated-docs.md`](../../docs/commands/08-generated-docs.md); the whole framework is described in [`@cofold/commands`](../commands).
